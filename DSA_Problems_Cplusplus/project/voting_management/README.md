# Voting Management Project

## Overview
This project implements a voting management system using C++. It allows users to create, manage, and participate in voting events.

## Features
- User registration and authentication
- Creation of voting events
- Casting and tallying votes
- Results display

## Requirements
- C++ compiler (e.g., g++, clang++)
- CMake (optional, for building)

## Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/AhmaadKaleeem/Programming_Practice.git
   cd DSA_Problems_Cplusplus/project/voting_management
   ```

2. **Compile the code**:
   ```bash
   g++ main.cpp -o voting_management
   ````

3. **Run the project**:
   ```bash
   ./voting_management
   ```

## Usage
- Follow on-screen prompts to register or login.
- Create a new voting event or participate in an existing one.
- After voting, results can be viewed in the results section.
